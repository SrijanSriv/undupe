Search open PRs by issue number, keyword, file path, or author before you start.

Open PRs that look like work from a PR that is already closed. Closed doesn’t always mean rejected: many maintainers ship a PR’s code in another commit and then close it, so these open PRs may no longer be needed.

How this works

Two open PRs are matched when:
  • they say they fix the same issue ("Fixes #N"), and their titles or files also agree;
  • their titles are nearly identical; or
  • they change the same uncommon files. Files most PRs touch (README, core modules) count for little.
PRs naming different languages (e.g. PHP vs Scala) are not matched on files alone, since they edit the same extractor files but do different work. “Same author” groups are one person submitting twice, not two people duplicating effort. “✓ Checked” means a person read the PRs and confirmed they are the same work; pairs a person rejected are not shown.

This is a heuristic, not a verdict. Matches come from titles, descriptions and file lists, not from reading the code. Always check before closing anything. Not affiliated with the repo’s maintainers.
