undupe About

Stop doing the same work twice.

On busy open-source repos, contributors often fix the same bug or build the same feature without knowing someone else already has. undupe finds those overlapping pull requests, so maintainers can close the extras and contributors can check before they start.

Or swap the domain in any repo link: github.com/owner/repo → undupe/owner/repo

How it works

01

Read every open PR

Titles, descriptions, linked issues and the files each one changes. Refreshed daily.

02

Match the same work

PRs that fix the same issue, carry near-identical titles, or change the same uncommon files get grouped.

03

Show it in one place

A list of duplicate groups for maintainers, and a search box for contributors: “is anyone already on this?”

Why it matters

When n people open a PR for the same fix, n − 1 of them wasted their time, and a maintainer still has to read them all. The duplicates usually arrive within days of each other: people simply can’t see the work is already in flight.

undupe only reads public data and never comments on or closes anything. Its matches are leads to check, not verdicts.
